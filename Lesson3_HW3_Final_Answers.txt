Q4. TRIMMOMATIC COMMAND, PARAMETER CHOICES, AND CLEANUP EVALUATION

Command actually used:
trimmomatic PE \
  -threads 2 \
  -phred33 \
  SRR1569760_sub_1.fastq.gz \
  SRR1569760_sub_2.fastq.gz \
  SRR1569760_1P.fastq.gz \
  SRR1569760_1U.fastq.gz \
  SRR1569760_2P.fastq.gz \
  SRR1569760_2U.fastq.gz \
  ILLUMINACLIP:NexteraPE-PE.fa:2:30:10 \
  SLIDINGWINDOW:4:20 \
  MINLEN:36

Parameter rationale:
- PE: process paired-end reads, retaining paired and unpaired output separately.
- -threads 2: use two processing threads.
- -phred33: use the Phred+33 quality-score encoding.
- ILLUMINACLIP:NexteraPE-PE.fa:2:30:10: detect and remove Nextera adapter sequences. The numeric settings specify seed mismatches (2), palindrome clipping threshold (30), and simple clipping threshold (10).
- SLIDINGWINDOW:4:20: trim a read once the mean quality within a sliding four-base window falls below Phred 20.
- MINLEN:36: discard trimmed reads shorter than 36 bases.

The resulting sequencing depth is 26.10x. Compared with the original ~30x depth, coverage decreased modestly as low-quality sequences, adapters, and unpaired/discarded reads were excluded. This 26.10x value refers to the cleaned paired reads only; surviving unpaired reads were not included in the calculation.
